# Words

An English vocabulary game for children, played in the browser. The child explores illustrated rooms and finds, names, and spells everyday objects.

- Game concept: [WORDS.md](WORDS.md)
- Technical design and implementation plan: [TECHNICAL.md](TECHNICAL.md)
- Art: [style guide](docs/art/style-guide.md) (cartoon, kawaii, isometric) and [making masks](docs/art/masks.md)
- Milestone reports: [M0: Project Setup](docs/milestones/M0.md), [M1: First Playable Room](docs/milestones/M1.md), [M4: Look and Identify, Recall and Spell](docs/milestones/M4.md)

## Getting started

Requires Node.js 22 or later.

```sh
npm install
npx playwright install chromium   # once, for end-to-end tests
npm run dev                        # http://localhost:8080
```

Add `?debug=hits` to the URL (dev server only) to see each object's clickable area, or `?debug=cutouts` to see only the object cut-outs. `npm run build:rooms` also writes a review image of the clickable areas to `reports/rooms/<room>-debug-hits.png`.

## Scripts

| Script | What it does |
|--------|--------------|
| `npm run dev` | Build the rooms, then start the Vite dev server on port 8080. |
| `npm run build` | Build the rooms, then the static game into `dist/`. |
| `npm run build:rooms` | Check the content, then turn each room's painting and masks into `public/assets/rooms/<room>/` (background, cut-out atlas, hit map, layout) and a review image in `reports/rooms/`. |
| `npm run masks` | Open the mask tool (dev server): click objects on a room painting to make their masks. See [docs/art/masks.md](docs/art/masks.md). |
| `npm run validate:content` | Check the lexicon, manifests, and masks without building; lists all problems and warnings. |
| `npm run build:test` | Build the test version (with the test bridge) into `dist-test/`. |
| `npm run make:placeholder-kitchen` | Redraw the placeholder kitchen painting and masks. |
| `npm run preview` | Serve the production build on port 4173. |
| `npm run lint` | Check code with ESLint and formatting with Prettier. |
| `npm run format` | Format with Prettier and apply ESLint fixes. |
| `npm run test` | Run the unit tests (Vitest). |
| `npm run test:watch` | Run the unit tests in watch mode. |
| `npm run test:e2e` | Build the test version, serve it, and run the end-to-end tests (Playwright, Chromium). |

CI runs lint, content validation, unit tests, build, and end-to-end tests on every push and pull request (`.github/workflows/ci.yml`).

## Deployment

Every push to `main` publishes the game to **https://truffio.github.io/Words/** with GitHub Pages (`.github/workflows/deploy.yml`). It can also be started by hand from the repository's **Actions** tab (*Deploy to GitHub Pages → Run workflow*).

One-time setup: repository **Settings → Pages → Source: GitHub Actions**.

The site is the static production build (`dist/`), without the test bridge or debug views. Any other static host works too: run `npm run build` and upload `dist/`.

## Project layout

```
content/          Source of truth for vocabulary and rooms (committed)
  lexicon.json      Shared English words
  schemas/          JSON Schemas for lexicon and manifests
  rooms/<room>/     manifest.json, room.png painting, masks/
public/assets/    Static files served as-is
  shared/           UI, feedback sounds, fonts
  rooms/<room>/     Generated by build:rooms (git-ignored)
src/
  core/             Game rules in plain JavaScript (no Phaser, no DOM)
  game/             Phaser scenes, input, feedback, audio
  shell/            HTML/CSS user interface around the canvas
  test-bridge/      Test-only hooks for end-to-end tests
  app.js            Connects shell, game, and core
  main.js           Entry point
tools/            Build and content scripts (build:rooms, validate:content, placeholder kitchen)
  lib/              Shared loading/checking (room-content.js) and pure algorithms (room-build.js)
  mask-tool/        Browser mask tool (Segment Anything + magic wand), dev server only
docs/art/         Art style guide and masking guide
reports/          Generated review images (git-ignored)
tests/
  unit/             Vitest tests
  e2e/              Playwright tests
```

The game uses a fixed logical resolution of 2048 × 1536, scaled to fit the window.
