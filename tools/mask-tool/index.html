    How to use

    1. Pick an object (or + another for a second chair, etc.).
    2. Click the object to select it. Shift+click (or right-click) a part that should not be included.
    3. If the outline is too small or too big, try outlines 1–3.
    4. Use the magic wand to add a flat-coloured area, Shift to remove one.
    5. Save, then the next object. Ctrl+Z undoes.

    Then run npm run build:rooms and check reports/rooms/<room>-debug-hits.png.
