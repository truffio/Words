    How to use

    1. + Add word adds a word to the room (a word already in the lexicon is reused); × removes one with its masks. The menu next to a word sets its difficulty.
    2. Pick an object (or + another for a second chair, etc.); the tools in the bar at the top edit its mask.
    3. Click the object to select it. Shift+click (or right-click) a part that should not be included.
    4. If the outline is too small or too big, try outlines 1–3.
    5. Use the magic wand to add a flat-coloured area, Shift to remove one.
    6. Or draw the area: Rectangle (drag), Points (click the corners, then click the first one or press Enter), or Free curve (drag around the object). Shift removes the area instead.
    7. Save, then the next object. Ctrl+Z undoes.
    8. Test taps, then click anywhere: it lists the objects a tap there detects in the game.

    Then run npm run build:rooms and check reports/rooms/<room>-debug-hits.png.
